- jbcrypt-0.4.jar

## Instalación

1. Descargar el proyecto.
2. Abrir Eclipse.
3. Importar el proyecto.
4. Importar la base de datos `gestion.sql`.
5. Verificar la conexión con MySQL.
6. Ejecutar la clase `Login.java`.
